# SNMP Manager

Сервис для управления SNMP-устройствами с веб-интерфейсом.

## Возможности

- Управление устройствами (CRUD операции)
- SNMP операции: GET, SET, WALK
- Управление каналами устройств
- Мониторинг в реальном времени через SSE
- Ролевая модель доступа (администратор/оператор)
- Хранение метрик в SQLite
